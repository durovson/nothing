# UI media

Положите сюда файлы `main_menu`, `wallet`, `deals`, `deal`, `faq`, `documents`, `settings`, `language`, `referrals`, `deal_create` и `deal_join` с расширением `.gif`, `.mp4`, `.png`, `.jpg` или `.jpeg`. После перезапуска бот подхватит их автоматически. При отсутствии файла используется `../menu.png`.
